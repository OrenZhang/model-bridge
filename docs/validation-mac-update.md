# macOS 一键更新验证

2026-11-06，版本 `0.1.0-alpha.3`，实现提交 `79d0dde`。

## 原生应用实测

使用打包应用内的生产更新模块、ASAR 内的 Universal 助手，以及本机生成的正式 ZIP 更新包，将正在运行的 `0.1.0-alpha.2` 升级到 `0.1.0-alpha.3`：

1. 校验 ZIP、应用标识、版本、架构与包内链接，在同一文件系统准备新版。
2. 独立助手确认就绪后，正常退出旧进程。
3. 助手原子交换应用目录，并通过 LaunchServices 自动打开新版。
4. 新版完成网关和桌面初始化，提交绑定任务与版本的启动确认。
5. 助手清理旧版，记录成功。

旧版 alpha.2 不包含更新助手，本次由验证程序调用新版生产模块准备升级，再正常退出旧版触发安装；没有拖动 DMG。alpha.3 及后续版本已将同一流程接入“安装并重启”按钮。

## 失败路径

使用临时目录中的原生 Cocoa 测试应用、真实 LaunchServices 和同一 Universal 助手测试：

- 新版启动并确认就绪后才删除旧版。
- 新版明确报告启动失败时，自动换回并重新打开旧版。
- 新版启动后卡住、不提交确认时，超时停止该进程，再换回并重新打开旧版。
- ZIP 损坏、版本/架构不匹配、安装目录不可写时，在退出前拒绝更新。
- 启动确认绑定私有任务目录、随机令牌、当前版本和应用路径。
- 更新包中的越界路径、绝对路径、外部链接、链接循环、大小写冲突及不完整目录在解压前被拒绝。

以上原生测试仅操作专门生成的临时应用，不使用用户模型账号或客户端配置。
