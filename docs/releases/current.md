## 0.1.0-alpha.3

macOS 新增一键安装更新。下载完成后点击“安装并重启”，无需拖动 DMG 替换。

- 使用经过 SHA-512 校验的 ZIP，检查应用标识、版本、架构与包内链接。
- 独立 Universal 原生助手等待旧进程退出，再原子替换应用并自动启动新版。
- 新版网关确认就绪后清理旧版；启动失败或超时会恢复并重新打开原版本。
- 安装准备或权限检查失败时保留正在运行的应用；账号、密钥与客户端配置保留。
- 不依赖系统 Node.js，不删除隔离属性，也不关闭系统安全检查。

DMG 继续用于首次安装。安装目录需可写；从 DMG 或 App Translocation 运行时需先安装到本地。旧的 0.1.0-alpha.2 不含更新助手，先升级到本版后，后续版本可直接在应用内安装。

提供 macOS Apple Silicon / Intel、Windows x64、Linux x64 / ARM64 安装包，文件校验见 SHA256SUMS.txt。
