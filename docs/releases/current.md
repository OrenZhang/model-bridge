## 0.1.0-alpha.7

GitHub 更新复用已有代理，修复弹窗遮挡提示。

- 更新检查和下载检测系统 / PAC、环境变量及应用内独立代理；外部代理不可用时，尝试已有订阅节点。检测使用独立会话，不修改系统代理或模型连接的配置。
- 使用代理前检测 GitHub；下载安装包时检测实际安装包地址，避免只能访问 GitHub 首页却无法访问资产下载域名的通道。
- 支持订阅内核和独立 HTTP 代理的用户名 / 密码认证，凭据只提供给匹配的代理，不发送给下载站点。
- 更新窗口显示所选代理或“订阅 / 节点”名称；没有可用代理时显示直连，代理下载失败仍保留直连重试和安装包校验。
- GitHub 下载使用独立节点路由，不修改 AI 自动优选结果或手动节点选择。
- 保存、同步、复制等反馈使用顶层提示，修复被原生弹窗和遮罩压住的问题；关闭弹窗后仍显示到超时结束，不抢输入焦点。
- 保留 alpha.6 的托盘后台运行、模型分页、认证助手更新及连接配置修复。

提供 macOS Apple Silicon / Intel、Windows x64、Linux x64 / ARM64 安装包，校验见 SHA256SUMS.txt。旧版正在执行的下载仍使用旧更新器，新代理逻辑安装本版后生效。
