## 0.1.0-alpha.6

一键更新、更新代理优先，并精简安装包。

- 点击“检查并更新”后，有新版本自动下载、校验、安装并重启；有模型请求进行时等待完成。后台定时检查仍只提示。
- 更新器检测系统 / PAC 代理并优先使用，失败后直连重试一次。窗口显示网络方式；不修改系统或模型连接的代理。
- 关闭窗口隐藏到托盘 / macOS 菜单栏，后台网关继续运行，从托盘菜单退出；自动更新保留正常退出重启流程。
- 官方认证助手更新到 Codex CLI 0.167.0。
- GPT 账号目录读取全部分页并刷新推理能力，按官方隐藏标记排除内部模型。新版助手隔离目录已包含截图中的 GPT-6.1 / GPT-6 系列；实际可用性以登录账号返回为准。
- 修复 API Key 同站点修改路径时丢失的问题，缺失密钥和 HTTP 401 提供明确提示。
- 更新订阅只重置关联连接，未关联连接的登录和网络保持独立。
- 编辑已有 API Key 连接时显示掩码和“已保存，留空保留”，不回填真实密钥。
- 移除官方登录流程未使用的代码执行辅助程序、内置搜索/终端资源、应用调试映射与多余语言包，保留认证主程序和内置 mihomo。
- 升级认证助手后，本地 macOS ARM64 ZIP 从约 253 MB 缩减到 243 MB，减少约 11 MB（4.2%）；其他平台以实际产物为准。
- 使用精简包中的真实 Codex 验证模拟 Kimi / MiniMax 三轮对话、工具调用和 thinking 回传。保留更新说明展开修复、AI 节点优选与运行期间防睡眠。

提供 macOS Apple Silicon / Intel、Windows x64、Linux x64 / ARM64 安装包，校验见 SHA256SUMS.txt。
