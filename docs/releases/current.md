## 0.1.0-alpha.4

新增自动 AI 节点优选，安装包附带 mihomo 内核，并在桌面应用运行期间保持系统唤醒。

- 订阅默认选择“自动 · AI 可用优选（最低延迟）”，保留手动固定节点。
- 按各连接的 AI 服务分别检测，在接口检测通过的节点中选择最低延迟，每 5 分钟复测，支持立即检测。
- 网络连接失败或 HTTP 502/503/504 后避开失败节点，后续请求使用其他可用节点；不自动重发已经发出的模型请求，也不中断已有流。
- 无可用节点时明确报错，不回退直连。检测不携带账号密钥，不生成模型内容；账号额度和模型权限仍以实际调用为准。
- macOS、Windows、Linux 安装包附带对应平台的官方 mihomo v1.19.32 压缩包，首次使用校验 SHA-256 并安装，无需再从 GitHub 单独下载；保留下载与离线导入入口。
- 桌面应用运行时阻止系统因空闲自动睡眠，托盘运行时保持生效；屏幕可以熄灭，退出后释放。

测试包含自动选择与定期检测回归、真实 mihomo 的受控节点路由、故障切换、已有流不中断及离线内核安装。macOS 保留一键安装并重启和更新失败回退。

提供 macOS Apple Silicon / Intel、Windows x64、Linux x64 / ARM64 安装包，文件校验见 SHA256SUMS.txt。Mihomo 的许可证与对应版本源码地址随安装包提供。
