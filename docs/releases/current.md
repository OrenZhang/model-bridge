## 0.1.0-alpha.8

网卡地址更清楚，协议接入更统一，隐藏模型从所有接口生效。

- 对外服务和复制配置窗口显示实际网卡名称，优先推荐当前使用的物理网卡地址；虚拟网卡明确标记并排在后面。
- 启用局域网访问后默认选择推荐地址；手动改选后保留选择，网卡地址失效时重新选择可用地址。监听地址 0.0.0.0 不会作为客户端地址导出。
- 网关始终接收 Responses、Messages、Chat Completions，按请求模型分发，并自动转换上游协议。
- 移除连接页容易混淆的单选协议入口，默认自动适配。高级设置支持指定一个或多个上游原生接口；优先使用相同协议，否则转为该连接的首个接口，不更换请求模型。
- 上游接口独立保存到连接，修复没有模型时无法保存选择，以及同步、重开后丢失选择的问题。
- 取消“对外提供”后，模型从 OpenAI / Anthropic 目录、Codex 目录及导出配置中移除；三种接口的直接请求和旧路由均返回 404，不访问上游。
- 隐藏规则按原始模型名持久保存，重新同步、新增同名账号或重新启用单个通道都不会绕过限制；在模型列表重新勾选可恢复。

提供 macOS Apple Silicon / Intel、Windows x64、Linux x64 / ARM64 安装包，校验见 SHA256SUMS.txt。
