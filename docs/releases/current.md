## 0.1.0-alpha.9

- 修复 Codex 在同一对话切换模型时被旧推理状态阻断的问题。新模型继续读取之前的消息和工具结果，当前轮保留所选模型的推理状态及工具调用。现有会话归属可自动延续。
- 移除独立的“客户端”侧栏入口。在“对外服务 → 本机接入与恢复”可接入 Codex、Claude Code 或恢复原始认证。“复制接入配置”继续提供其他设备使用的脚本与配置。
- 修复 DeepSeek 流式输出带空推理字段时断流的问题。跨协议请求可使用 Codex 客户端工具发现及按需加载的工具。

提供 macOS Apple Silicon / Intel、Windows x64、Linux x64 / ARM64 安装包。校验文件为 SHA256SUMS.txt。
